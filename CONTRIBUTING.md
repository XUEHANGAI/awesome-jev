# Contributing

Thanks for helping keep this list useful. The ecosystem is young, so the bar is "real and inspectable", not "famous".

## How to add an entry

1. Pick the section that best matches what Jev *decides* in your project.
2. Add one line in this format:

   ```
   - [Name](URL) - One sentence: what state it evaluates, what typed questions it asks, and what the code does with the answer.
   ```

3. Open a pull request. One entry per PR is fine.

## Rules

- The project must use Jev / TypeSafe's System One API — or be explicitly Jev-inspired (then it belongs in [Research and open models](README.md#research-and-open-models), and the description must say so).
- Link to something public and verifiable: a repo, a live demo, or a post with enough detail to check the claim.
- One sentence per entry. Describe what it does, not why it is great. No marketing language, no "revolutionary".
- If you built or maintain the project, say so in the PR description. Self-submissions are welcome; undisclosed ones are not.
- Mark experimental, demo, or dry-run-only projects (trading, financial actions, home automation) as such.
- No unverified performance numbers in the entry line. Numbers belong in your own repo or post, linked.
- Don't reformat, reorder, or "fix" unrelated entries in the same PR.

## Also submit to the directory

This list is maintained alongside [madewithjev.com](https://madewithjev.com), a directory of Jev builds with the cost and latency each author reported. If your project has numbers, submit it at [madewithjev.com/submit](https://madewithjev.com/submit) too.

## Not sure where something fits?

Open an issue with the link and a sentence about what it does. We'll figure out the section together.
